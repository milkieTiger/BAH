# User Stories

## Epic 1 - Evergreen Website (P0)

### US-001 About Us

As a visitor, I want to learn about BAH so that I understand the convention.

---

### US-002 Code of Conduct

As a visitor, I want to read the Code of Conduct so that I understand expected behavior.

---

### US-003 Terms & Conditions

As a visitor, I want to read the Terms & Conditions before participating.

---

### US-004 Volunteer Application

As a visitor, I want to apply as a volunteer.

---

## Epic 2 - Theme Reveal (P1)

### US-005 View Theme Landing Page

As a visitor, I want to see the yearly convention theme.

### US-006 View Venue Information

As a visitor, I want venue information before planning my trip.

### US-007 View Guest of Honor

As a visitor, I want information about this year's Guest of Honor.

### US-008 Browse Travel Guide

As a visitor, I want travel recommendations.

### US-009 Submit Art

As an artist, I want to submit artwork for the convention.

---

## Epic 3 - Accounts (P1)

### US-010 Create Account

As a visitor, I want to create an attendee account.

### US-011 Login

As an attendee, I want to securely log into my account.

### US-012 Edit Profile

As an attendee, I want to customize my attendee profile.

---

## Epic 4 - Ticket Registration (P1)

### US-013 Purchase Ticket

As an attendee, I want to purchase a convention ticket.

### US-014 View Registration

As an attendee, I want to review my registration.

### US-015 Modify Registration

As an attendee, I want to edit my registration while registration is open.

---

## Epic 5 - Organizer Submissions (P2)

### US-016 Dealer Submission

As a dealer, I want to apply for a Dealer's Den booth.

### US-017 Panel Submission

As a panelist, I want to submit a panel proposal.

---

## Epic 6 - Final Information Release (P2)

### US-018 View Schedule

As an attendee, I want to browse the event schedule.

### US-019 View Dealer Layout

As an attendee, I want to browse the Dealer's Den layout.

### US-020 View Booth Listing

As an attendee, I want to browse participating dealers.

### US-021 Badge Pickup

As an attendee, I want to choose my badge pickup option.
